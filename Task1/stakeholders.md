# Карта стейкхолдеров

|  |  |  |
| --- | --- | --- |
| Стейкхолдер | Интерес / цель | Что уточнить |
| Бизнес-спонсор | Скорость, предсказуемость, устойчивость, новые сервисы | Цели, приоритеты, бюджет, риск-аппетит, критерии успеха |
| Руководитель клиентской поддержки | Прозрачность, меньше ручных операций, SLA | Боли, сценарии исключений, требования к статусам и истории |
| Руководитель команды заказов и оформления | Владелец ключевого процесса, знает фактические сценарии, стабильность и проблемы | Реальный процесс, исключения, ручные операции, узкие места |
| Технический лидер / ведущий разработчик монолита | Техническая реализуемость целевой архитектуры, снижение тех долга | Архитектура, зависимости, ограничения, узкие места, тех долг, |
| Руководитель логистики | Сроки, маршрутизация, партнёры | Логистические сценарии, интеграции, отклонения |
| Руководитель платёжных интеграций | Оплата, возвраты, провайдеры | Платёжные сессии, повторные операции, транзакции, возвраты, ограничения провайдеров |
| Команда аналитики | Единые данные, отчётность | Источники данных, расхождения, требования к агрегатам |
| Инфраструктура и эксплуатация | Вычислительные и storage ресурсы, RTO/RPO | Ограничения, SLA/SLO, деградация, миграция |
| ИБ, Комплайнс | Меры обеспечения требованиям информационной безопасности, соответствие требованиям регуляторов в части ПДН, платежной информации | Требования безопасности, импортонезависимость |
